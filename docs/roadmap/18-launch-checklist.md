# 18 — Launch checklists

## Beta launch (end of week 12) — free Levels 0–1

**Product**
- [ ] Sign-up with phone OTP works on Roshan, AWCC, MTN, e&/Etisalat and Salaam numbers (or the fallback works)
- [ ] Level 0 and Level 1 complete in Pashto and Dari, reviewed
- [ ] Quizzes, final exams and certificates work; verify page live
- [ ] PWA installs; offline lessons play; progress syncs
- [ ] Tested on 3 cheap Android phones on 3G
- [ ] Terms, privacy, refunds, certificate policy pages live in 3 languages
- [ ] Error monitoring, backups, uptime monitor on

**People**
- [ ] 100 beta testers recruited (mix: men/women, Pashto/Dari, cities/provinces, ages)
- [ ] Feedback form in both languages; a Telegram beta group
- [ ] Support person ready on Telegram/WhatsApp

**Marketing**
- [ ] 30+ videos on YouTube; channels active for 6+ weeks
- [ ] Launch post + video in both languages
- [ ] "7-day AI challenge" ready to run

## Paid launch (end of week 16)

**Gate check:** 500+ active learners · 30%+ Level 0 completion · fixes from beta done

- [ ] HesabPay live; tested with real small payments; refunds tested
- [ ] Vouchers printed for agents in 3 cities; agent commission rules signed
- [ ] Level 2 published (both languages) + 1 industry track
- [ ] Membership plan live
- [ ] Prices published; launch discount (e.g. 30% for the first 2 weeks)
- [ ] Scholarship form live (women, orphans, low-income), with sponsor slots
- [ ] Android app in the Play Store (or in closed testing)
- [ ] Ads ready; launch email/Telegram/SMS message to all beta users
- [ ] Dashboard: daily sign-ups, purchases, completion, support tickets

## After every launch
- [ ] Day 1, 3, 7: check errors, payment failures, support questions
- [ ] Week 2: survey students; fix the top 3 issues
- [ ] Week 4: review numbers against file 19 targets
