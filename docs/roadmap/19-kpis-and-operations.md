# 19 — KPIs and operations

## Numbers to track weekly

| Area | KPI | Good target (first year) |
|---|---|---|
| Reach | New YouTube subscribers, Facebook/Telegram followers | Steady growth week over week |
| Acquisition | New LMS sign-ups | 500/week by month 6 |
| Activation | % of sign-ups who finish the first lesson | 60%+ |
| Engagement | Weekly active learners | 30% of all learners |
| Completion | % who finish a course they started | 25%+ for free, 50%+ for paid |
| Quality | Lesson rating (1–5), drop-off lesson | 4.5+; fix any lesson where 20%+ quit |
| Revenue | Paying students, revenue by gateway, average order value | Break-even (~85 members) by month 12 |
| Conversion | Free → paid | 3–5% |
| Certificates | Issued per week; verify-page visits | Growing |
| Support | First response time | Under 4 hours |
| Channels | YouTube click-through rate, average view duration | CTR 5%+; 40%+ retention |

## Team routine

| When | What |
|---|---|
| Daily (15 min) | Check support, payments, errors; post on channels |
| Monday | Plan the week's lessons and posts |
| Wednesday | Editor review day |
| Friday | Publish, analytics review, write down one improvement |
| Monthly | Revenue report, payouts (marketplace), course quality review, update the roadmap |
| Quarterly | Survey students; review prices; plan the next levels |

## Tools for operations
- Content pipeline board (Notion/Trello): Outline → Script → Review → Record → Edit → QA → Published
- Shared drive with the folder system from file 13
- Support: Telegram bot + a shared inbox
- Accounting: separate HesabPay (AFN) and Stripe (USD) ledgers; monthly reconciliation
